# Варіант 24 Рубан Андрій ПДМ-61 — лінійне програмування на C# / Windows Forms

Навчальний застосунок для графічного розв'язання задачі лінійного програмування.

## Умова

Мінімізувати `Z = 2x1 + 5x2` за обмежень:

- `7x1 + 2x2 >= 14`
- `5x1 + 6x2 <= 60`
- `3x1 + 8x2 >= 24`
- `x1 >= 0`, `x2 >= 0`

## Результат

Допустимі вершини:
- `(0; 7)`, `Z = 35`
- `(0; 10)`, `Z = 50`
- `(12; 0)`, `Z = 24`
- `(8; 0)`, `Z = 16`
- `(1,28; 2,52)`, `Z = 15,16`

Оптимум: `x1 = 1,28`, `x2 = 2,52`, `Zmin = 15,16`.

## Запуск

Потрібен Windows і .NET 8 SDK.

1. Відкрийте термінал у папці проєкту.
2. Виконайте `dotnet restore`.
3. Виконайте `dotnet run`.

Графік побудовано за допомогою бібліотеки ScottPlot.WinForms (NuGet). Вихідний код містить окремий розв'язувач, інтерфейс, покроковий опис, таблицю вершин та графік.

> Примітка: це вихідний проєкт, який потрібно зібрати на Windows із доступним .NET SDK та відновленням NuGet-пакетів.
